# Tutorials

These tutorials are for first successful runs. They use explicit commands and
fixed example addresses so that failures are easy to localize.

- [First TCP echo run on bare metal](first-tcp-echo-bare/README.md)
- [First UDP echo run on bare metal](first-udp-echo-bare/README.md)

After a tutorial works, use the [how-to guides](../how-to/README.md) to adapt
the setup to a different NIC, CPU layout, VM deployment, or application.
